# Technology blog profile

Use this profile for long-form technical writing that helps an AI undergraduate
learn product engineering: turning model or software capability into a
deliverable, testable, supportable product.

Typical items include engineering deep dives, implementation walkthroughs,
product teardowns, architecture discussions, incident retrospectives, evaluation
methods, cost models, reliability and fallback designs, technical tutorials, and
case studies that expose concrete requirements or delivery constraints.

Do not use this profile for short release announcements, routine project
updates, news reports, API reference pages, complete academic papers, thin
search-optimized tutorials, or promotional material without concrete technical
reasoning. A frontier-research explainer belongs here only when it connects to a
real product decision; otherwise use the research profile. Do not treat model
training as the default product-engineering path.
