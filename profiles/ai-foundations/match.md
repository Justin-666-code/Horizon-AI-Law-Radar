# AI foundations profile

Use this profile for content that helps an人工智能大二 build durable foundations in mathematics, machine learning, deep learning, Python engineering, model training, evaluation, experiment design, and research reading.

Typical items include concept explanations, courses, textbook chapters, guided tutorials, worked examples, reproducible notebooks, engineering explainers, evaluation guides, and first-hand lessons about learning or building AI systems.

Do not use this profile for product release notes, funding news, opinion without technical substance, research papers whose prerequisites are too advanced to explain, or promotional course advertising. A frontier paper belongs here only when the source itself is primarily teaching a transferable foundation.
